# i18n — локализация

Движок — `fluent.runtime` (`.ftl`); механика (`I18NFormat`-виджет, `install_i18n`-middleware,
`FluentTranslator`, `LocaleResolver`) — в `tgbotkit`. Включён из коробки (`config.py`). Шаблон
описывает **локали, каталоги, резолвер**. Если бот одноязычный — оставь одну локаль.

## Locales & default
<Поддерживаемые локали и дефолт. Reference: `ru` (дефолт) + `en`. `BOT_I18N_DEFAULT_LOCALE`
(kit-дефолт `en`, шаблон переопределяет на `ru` в `config.py`). Пример: `ru`, `en`, дефолт `ru`.>

## Catalogs
<Переводы — `locales/<lang>/<resource>.ftl`, **один `.ftl` на фичу** (имя ресурса = префикс фичи).
Каталог регистрируется в `config.py` (`_LOCALES_DIR`, `_I18N_RESOURCES`). Reference-ресурсы:
`common.ftl`, `start.ftl`, `profile.ftl`, `payments.ftl`, `lang.ftl`. Ключи — `<feature>-<name>`
(напр. `profile-edit-name`, `common-back`). Динамику даёт `Format("{...}")`, статику —
`I18NFormat("<key>")`.>

## Resolver
<Цепочка резолва локали (`extensions.py: ChainResolver`): сначала явный выбор пользователя
(`FromCachePref`, фича `lang` пишет в cachekit), затем `language_code` Telegram (`FromUserLanguage`).
Опиши приоритет резолва для своего бота. Middleware навешан и на `DIALOG_EVENT_NAME` (фоновые
апдейты тоже локализуются).>

## Language switch
<Фича смены языка (`features/lang/`): диалог выбора локали, пишет выбор в cachekit → резолвер
подхватит на следующем рендере. Команда `/language`. Если не нужна — удалить фичу + ресурс
`lang.ftl`.>

## Generates
<Что de-template родит:
- i18n-конфиг в `config.py` (`I18nConfig`: locales_dir/default_locale/resources)
- `BOT_I18N_DEFAULT_LOCALE` в `.env.example`
- `locales/<lang>/<feature>.ftl` каталоги
- `OptionalLocaleResolver` (ChainResolver) в `extensions.py`
- (смена языка) фича `lang`>

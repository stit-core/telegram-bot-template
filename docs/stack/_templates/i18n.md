# i18n — переводы (опц.)

Опциональный артефакт: заполняется, если бот многоязычный или тексты вынесены в Fluent. Бот без
i18n прунит фичу `lang` и держит тексты инлайн — тогда этот артефакт пуст/удалён.

## Locales & default
<Список локалей, дефолт-локаль (шаблон — `ru`; kit-дефолт — `en`). `BOT_I18N_DEFAULT_LOCALE`,
`BOT_I18N_PATH`. Каталог — `bot/locales/<locale>/<resource>.ftl`.>

## Resources
<`.ftl`-ресурсы = префиксы фич (один файл на фичу: `common`/`start`/`profile`/…). Ключи статичных
подписей (`I18NFormat`) vs динамика (`Format` из getter). Превращение текстов стратегии в `.ftl` —
работа этого репо.>

## Resolver
<Как выбирается локаль: `ChainResolver` (явный выбор фичи `lang` ≻ `language_code` Telegram).
Хранилище предпочтения (`LocalePrefStore` в кэше).>

## Generates
<Что de-template родит:
- `_I18N_RESOURCES`/`_DEFAULT_LOCALE` + `I18nConfig` в `config.py`
- `resolver` (`ChainResolver`) в `ExtensionProvider`
- env: `BOT_I18N_*`
- каркас каталога `locales/<locale>/`>
